      Selected achievements

      Production connectivity root cause analysis

      Traced a latency-sensitive IPv6 and IPv4 connection failure through routing behavior, Node.js Happy Eyeballs implementation details and application timeout behavior, leading to a practical mitigation. Instead of racing IPv6 and IPv4 attempts, Node.js cancelled each attempt when a short timer fired and only then tried the next address, so on slow routes nothing ever connected.

      Distributed job orchestration

      Designed rollback-aware orchestration for multi-step jobs using transaction IDs and compensating actions to support safer recovery from partial failures.

      Reusable platform foundations

      Built shared configuration and data foundations for multiple cnMaestro applications instead of duplicating product-specific backend implementations.

      Security research · HackerOne

      Identified and responsibly disclosed a payment-flow vulnerability affecting Cleartrip; the report was validated and awarded through HackerOne.
