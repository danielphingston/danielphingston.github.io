    Stuck at max: why Hyper-V Dynamic Memory won't let go of Linux RAM

    My Linux VM asked Hyper-V for 20.9 GB. It was using 4. Dynamic Memory was on, and the Ubuntu VM still held all 12 GB. The Linux balloon driver reports reserved memory as demand. A 100-line kretprobe module reports real use instead, and the VM now settles near 6.8 GB.
